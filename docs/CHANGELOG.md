# Changelog

Each extension is versioned on its own and keeps its own changelog, which is the source of truth for its versions. Repo-wide changes, such as docs and CI, aren't versioned. Tags use the per-extension scheme `<extension>-vX.Y.Z`, set by the first release, `github-v0.1.0`; GitHub Releases, when published, use the same tag.

| Extension | Changelog |
| --- | --- |
| github | [github/CHANGELOG.md](../github/CHANGELOG.md) |
| mcc | [mcc/CHANGELOG.md](../mcc/CHANGELOG.md) |
| tabs | [tabs/CHANGELOG.md](../tabs/CHANGELOG.md) |
| sshtab | [sshtab/CHANGELOG.md](../sshtab/CHANGELOG.md) |

Each changelog starts with an `## Unreleased` section, followed by `## X.Y.Z (YYYY-MM-DD)` sections that group entries under headings such as Added, Changed and Fixed.
