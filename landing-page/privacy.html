Privacy Policy

Product: rex-extensions and this site

This site is a static page with no analytics, cookies or forms of its own. The extensions run on your machine as your user; they send data only through the tools they call, which this page names.

1. Information we collect

This site has no sign-in, form, analytics script or cookie. GitHub Pages serves it, and handles each request under GitHub's privacy statement.

The extensions send nothing to their author. On your machine they read and write:

  • github: the repo of the focused pane, through git, and its pull requests and issues, through gh or glab. It keeps its profiles in ~/.config/rex-github/profiles.json, and which list you chose, the panel's width and the merge mode in ~/.local/state/rex-github/.
  • mcc: mcc's usage cache, through mcc usage, and this machine's CPU, memory, disk and network figures. It keeps whether the panel was collapsed in ~/.local/state/rex-mcc/collapsed.
  • sshtab: the command line of the program in a pane, and from an agent's environment only CLAUDE_CONFIG_DIR, CODEX_HOME, EDITOR and VISUAL. In ~/.cache/rex-sshtab/ it keeps a log and, for each pane with an agent, the agent's name, session id and folder; no prompt is kept.
  • tabs: the folder and title of each tab, to name sessions and tabs. It keeps its watcher's pid, and whether you turned it off, in ~/.cache/rex-tabs/.

2. How we use it

Only to show the panels and names you see, and to type the ssh and resume commands sshtab types. Nothing leaves your machine for the author.

3. Cookies and analytics

None on this site. The slideshow stores nothing in your browser.

4. Sharing and processors

  • GitHub or GitLab, through gh or glab, when the github panel reads, merges or closes; and your repo's remote, when it runs git pull or git fetch after a merge.
  • Anthropic, when you press refresh in the mcc panel: mcc sends each account's login to Anthropic's usage endpoint.
  • Your other machines, over SSH, when mcc is set up to reach them: every 30 seconds while the mcc panel is open.
  • GitHub Pages, which hosts this site.

5. Retention

The files the extensions write stay on your machine until you delete them. sshtab deletes its record of agent sessions when you turn Restore Agent Sessions off.

6. Your choices

Remove an extension with node ~/.config/rex/rex-extensions/<extension>/install.js --remove, and delete the files listed above. The author holds no data about you to access, correct or export.

7. Changes to this policy

This page is in the public repo; each change to it is a commit in its history.
