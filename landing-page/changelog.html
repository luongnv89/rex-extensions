rex-extensions

Extensions for Rex, the terminal multiplexer. One install.js each.

Install from GitHub

Changelog

Each extension is versioned on its own. Newest first; the per-extension changelogs in the repo hold every detail.

Unreleased

On main, not yet in a tagged release.

New

  • sshtab: a tab or split pane opened from one that's ssh'd into a machine connects to that machine too, with the same ssh options.
  • sshtab: Claude Code sessions, and Codex, OpenCode, Cursor Agent and pi sessions started with a session id, resume in their panes and folders after Rex restarts.
  • sshtab: Restore Agent Sessions in the command palette turns agent session restore off or on, apart from same-machine tabs.
  • tabs: the sidebar shows the machine in each session's name and the folder in each tab's name, including tabs that run ssh, and keeps the names you give them.
  • mcc: a ► marks the profile mcc run would start in the folder of the pane you work in.
  • mcc: API-key profiles show what mcc estimates they spent this month, with a bar against the budget when one is set.

Improved

  • mcc: accounts are listed by weekly use, least first, as mcc usage sorts them.

Fixed

  • github and mcc: the panels follow your pane and size themselves again under a Rex that sets only REX_BLOCK.
  • mcc: the ► mark shows for a profile with an account label.
  • mcc: a moved or upgraded mcc no longer leaves the panel stuck on old numbers.
  • mcc: the panel stays tall enough for every account after you drag the border above it.

Action needed

  • sshtab: if you installed its first version, which bound cmd+t, run install.js again to give cmd+t back to Rex's New Tab.

github 0.1.0

2026-11-25 · the first public release of the PR and issue panel

New

  • See the open pull requests and issues of the repo you're in, from GitHub or GitLab, in a pane on the right of the tab.
  • Start an agent on an issue or a pull request with its Resolve or Review button, in a new pane beside yours.
  • Choose the agent, model and thinking level with agent profiles for seven harnesses, test a profile before you use it, and import profiles from mcc.
  • Send a prompt of your own from each button, and rename the button to match.
  • Run one agent on several issues with Auto-pilot.
  • Merge a pull request or close an issue from its row, with a second press to confirm.
  • Use every button from the keyboard, with a key for each.
  • Edit profiles, button labels and prompts, and the merge mode in a Settings view with three tabs.

Improved

  • The panel keeps the width you drag it to, also after Rex restarts.
  • Resolve and Review open the agent's pane beside your agent, side by side.

Fixed

  • The panel works in a session on a remote host.
  • A profiles file saved by a newer version of the panel now says so.

Action needed

  • With no profile assigned, Resolve and Review start Claude Code through mcc run. Assign a profile to keep using another agent.

mcc 0.1.0

2026-11-05 · the first release of the mcc usage panel

New

  • See the 5-hour and weekly Claude Code usage of every mcc account in a strip along the bottom of the tab.
  • Look every account up live with the refresh button or r; between refreshes the panel rereads mcc's cache every 30 seconds.
  • The panel fits its height to its rows, and collapses to one line that shows the highest percent of each window.
